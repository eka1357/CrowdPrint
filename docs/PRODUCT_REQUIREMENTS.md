# Product Requirements Document (PRD): Crowdprint

## 1. Executive Summary
**Product Name:** Crowdprint  
**Tagline:** Cultural Intelligence for Live Event Sponsorship & Brand Activations.  
**Target Buyers:** Festival promoters (Live Nation, AEG, independent Boiler Room/warehouse promoters), talent agencies, and experiential marketing teams.  
**Core Problem:** Event organizers leave millions on the table or pitch generic sponsors (Red Bull, Heineken) because they guess which brands align with their lineup. Plain LLMs hallucinate generic correlations.  
**The Crowdprint Solution:** An autonomous sponsorship strategist agent that ingests an event lineup, venue city, and commercial constraints, queries the Qloo Taste AI Graph (`250M+` cultural entities), filters candidates through a deterministic Commercial Rules Engine, and outputs an inspectable, evidence-backed sponsor shortlist alongside a side-by-side "Qloo vs. Plain LLM" comparison.

## 3. Core User Flows
### Flow A: The 10-Second Judge Preset (Zero Typing)
1. Judge opens the live URL.
2. Above the fold, judge clicks one of 3 real-world Event Presets:
   - **Preset 1:** *Brooklyn Warehouse Electronic* (Fred again.., Four Tet, Peggy Gou, Overmono | NYC | $150k Min Tier | No Hard Liquor)
   - **Preset 2:** *Silver Lake Indie & Alt-R&B Outdoor* (Khruangbin, Steve Lacy, Clairo, Men I Trust | Los Angeles | $75k Min Tier | Eco-Conscious Only)
   - **Preset 3:** *Hackney Underground Jazz & Grime* (Ezra Collective, Little Simz, Yussef Dayes | London | $50k Min Tier | Footwear Conflict Locked: Nike)
3. The Manus-style left execution pane replays/executes the Qloo entity resolution and insights calls with live badges.
4. The right workspace renders the Ranked Sponsor Shortlist, the Rejected Brands Log (commercial conflicts), the Qloo-vs-Plain-LLM Diff toggle, and the Evidence Drawer.

### Flow B: Custom Event Brief Execution
1. User enters 2–6 artist names, selects a city, sets budget floor, and checks restricted brand categories (e.g., Alcohol, Fast Fashion, Crypto, Sportswear).
2. Agent resolves artists via Qloo `/search`, queries `/v2/insights` for cross-domain brands and taste tags, applies deterministic rules, and streams results.

## 4. Strict Guardrails (Pass/Fail Criteria)
- **No Unlabeled Hallucinations:** Every affinity score, entity ID, and overlap tag must come directly from the Qloo API response.
- **Signal vs. Creative Inference Separation:** Any activation concept generated by the LLM must either cite a specific retrieved Qloo entity/tag (`[Qloo Signal Grounded]`) or carry an amber badge (`[Creative Suggestion - LLM Inferred]`).
- **Day-2 API Feasibility Gate:** Before building Phase 4 UI features (like neighborhood maps), `scripts/gate_test.mjs` must verify real API outputs.
