## 2. Mock-First Build Discipline (While Waiting for Qloo API Key)
- The environment variable `QLOO_MOCK_FIXTURE_MODE=true` is active until the live `QLOO_API_KEY` arrives.
- Build `src/lib/qloo.ts` with a clean dual-mode switch:
  - When `QLOO_MOCK_FIXTURE_MODE === 'true'`, return realistic Qloo entity URNs (`urn:entity:artist:...`, `urn:entity:brand:...`) and affinity scores from `src/data/mock_fixtures.ts`, and tag every `QlooCallTrace` with `mode: 'MOCK_FIXTURE'`.
  - When `QLOO_MOCK_FIXTURE_MODE === 'false'`, execute real HTTP requests against `QLOO_API_URL` using the `X-Api-Key` header and tag traces with `mode: 'LIVE_QLOO'` (or `'CACHED_QLOO'`).
- Never display mock data as live data—always surface the active `mode` badge in the top header bar and left execution trace pane.

## 3. Strict Attribution & Anti-Hallucination Rules
1. **No Invented Scores:** Every affinity score and entity URN displayed on a Sponsor Card or inside the Evidence Drawer must trace directly to the payload returned by `src/lib/qloo.ts`.
2. **Signal vs. Creative Guess Badges:** In the Activation Generator (`src/lib/llm.ts`), every proposed activation must separate:
   - `qlooSignalCited`: Verified tag or cross-domain entity from Qloo (rendered with an Emerald `#10B981` badge).
   - `creativeExtension`: Operational execution idea generated by the LLM (rendered with an Amber `#F59E0B` badge).
3. **Deterministic Commercial Rules (`src/lib/rules.ts`):** Category exclusions, age restrictions, and competitor locks must be enforced in pure TypeScript code—never delegated to an LLM prompt. Blocked high-affinity brands must be preserved in the `rejected[]` array and shown in the Commercial Rule Rejections audit tab.

## 4. UI & Styling Rules (Bklit + Manus + 21st.dev)
- **Theme:** Deep obsidian canvas (`#090A0F`), elevated dark slate cards (`#11131C`), `1px solid rgba(255,255,255,0.08)` borders, and `JetBrains Mono` for all entity URNs, latency readouts, and affinity percentages.
- **Forbidden Libraries:** Do NOT install or use `lenis` or `@barba/core`—preserve fast, native browser scrolling inside data tables and slide-over drawers.
- **Zero-Typing Judge UX:** The landing page must always load with the 3 one-click Judge Presets visible above the fold.
